# Repository Guidelines

## Git Commit Conventions
When creating commits for this repository, always adhere strictly to the following format:
- **Format**: `<type>[scope]: <description> <context>`
- **Language & Mood**: English, imperative mood (e.g., `add`, `update`, `refactor`, `fix`).
- **Components**:
  - `<type>`: `feat`, `fix`, `refactor`, `perf`, `chore`, `docs`, `style`, `test`.
  - `[scope]`: Target component, feature, or domain enclosed in square brackets (e.g., `[startmenu]`, `[emulator]`, `[games]`, `[windows]`, `[rules]`).
  - `<description>`: Concise summary of what was done in imperative mood.
  - `<context>`: Brief explanation, motivation, or relevant details.
- **Example**:
  `feat[games]: add Ball Blaster DOS arcade title configure standard DOSBox profile in Start Menu`
